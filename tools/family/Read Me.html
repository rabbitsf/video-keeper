Video Keeper

Version {{VERSION}} · for Mac

Adds a button to your browser that finds videos on the page you're viewing and saves them to your Downloads folder. With the helper app (part 2) it can also save YouTube videos.

1. Add it to Firefox (1 minute)

  1. Open Firefox.
  2. Drag the file {{XPI}} from this folder onto the Firefox window.
  3. Click Add, then OK. A welcome page opens with a few tips.
  4. Click the puzzle-piece icon in the toolbar and pin Video Keeper.
If the button shows “Allow access to websites…”, click Allow once — it needs this to see videos on pages.

2. YouTube downloads (optional, 2 minutes)

  1. Double-click {{PKG}}.
  2. Click through the installer and enter your Mac password when asked.
  3. Quit and reopen Firefox.
Then open a YouTube video, click the Video Keeper button, choose a quality and click Download with yt-dlp. You'll get a notification when it's saved.

The helper is signed and checked by Apple, so it opens without warnings, and it keeps itself up to date. After installing you can delete this folder.

Using Chrome instead?

Chrome can't install it from a file, so it takes a few more steps:

  1. Move the Chrome extension folder somewhere permanent, e.g. your Documents folder (Chrome keeps using it from there).
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the Chrome extension folder.
  4. For YouTube, install the helper from part 2 (it works with Chrome too), then restart Chrome.

Good to know

  • Works on most sites with ordinary videos and streams. It can't save copy-protected video (Netflix, Disney+, Prime Video, etc.) or live streams.
  • Updates: the YouTube helper updates itself, and the Firefox add-on will update itself once it is published in Firefox Add-ons. The Chrome copy doesn't update — you'll get a new folder when there is one.
  • To remove the helper: open Terminal and run sudo "/Library/Application Support/VideoKeeper/uninstall.sh"
  • Please only download videos you're allowed to: your own, openly licensed ones, or where the site permits it.
