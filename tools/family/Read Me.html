Video Keeper

Version {{VERSION}} · for Mac

Adds a button to your browser that finds videos on the page you're viewing and saves them to your Downloads folder. It can also save YouTube videos once the YouTube helper is set up (part 2).

1. Add it to Firefox (1 minute)

  1. Open Firefox.
  2. Drag the file {{XPI}} from this folder onto the Firefox window.
  3. Click Add, then OK.
  4. Optional: click the puzzle-piece icon in the toolbar and pin Video Keeper.
If the popup shows “Allow access to websites…”, click Allow once — it needs this to see videos on pages.

2. Set up YouTube downloads (optional, 5–20 minutes)

  1. Double-click Install YouTube Helper.command.
  2. If macOS says it can't be opened or can't verify the developer: click Done, open System Settings → Privacy & Security, scroll down, click Open Anyway next to “Install YouTube Helper.command”, and confirm with your password.
  3. A Terminal window opens and installs everything. When asked for your Mac password, type it and press Return — nothing appears while you type; that's normal.
  4. When it says ✅ All set, press any key, then quit and reopen Firefox.
Then open a YouTube video, click the Video Keeper button, choose a quality and click Download with yt-dlp. You'll get a notification when it's saved.

After setup you can delete this folder — the helper keeps working.

Using Chrome instead?

Chrome can't install it from a file, so it takes a few more steps:

  1. Move the Chrome extension folder somewhere permanent, e.g. your Documents folder (Chrome keeps using it from there).
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the Chrome extension folder.
  4. For YouTube, run part 2 above (it sets up Chrome too), then restart Chrome.

Good to know

  • Works on most sites with ordinary videos and streams. It can't save copy-protected video (Netflix, Disney+, Prime Video, etc.) or live streams.
  • Updates don't install automatically — you'll get a new copy of this folder when there is one.
  • Please only download videos you're allowed to: your own, openly licensed ones, or where the site permits it.
