Video Keeper Helper

This adds the YouTube download button to the Video Keeper browser extension for Firefox and Chrome.

It installs:

  • a small helper program the extension talks to, and
  • yt-dlp, the open-source tool that downloads the video, with a private copy of Python to run it and QuickJS, a small JavaScript engine YouTube downloads need, and
  • FFmpeg, used to combine a video's picture and sound into one MP4 file.

Everything goes into /Library/Application Support/VideoKeeper and is signed and notarized by Apple. Because websites change often, the helper keeps yt-dlp current by itself: at most once a day it checks yt-dlp's official GitHub releases and, if there is a new version, downloads it into your user folder after verifying its published checksum. No other programs are ever downloaded.

Videos are saved to your Downloads folder. The helper collects no data and only runs while the extension is using it.

To uninstall later, run in Terminal:
sudo "/Library/Application Support/VideoKeeper/uninstall.sh"
